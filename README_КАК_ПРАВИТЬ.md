# L.I.S.A. Remote Reception — как править сайт

Этот лендинг заменяет старый сайт lisa-is.com (старая версия сохранена, см. ниже).

## Файлы

```
lisa-is-site/
├── index.html          ← вся вёрстка + все тексты (RU) + CSS
├── js/calc.js          ← ВСЕ ФОРМУЛЫ (экономия, налоги, конфигурация тарифов)
├── js/app.js           ← логика страницы: ползунки, формы, галерея
├── assets/             ← реальные фото и видео L.I.S.A. (НЕ менять на AI-картинки)
└── _old/index_OLD_2026-09-29.html   ← старая версия страницы
```

## Модель (js/calc.js)

L.I.S.A. сдаётся в аренду — покупки комплекта и капитальных вложений нет, поэтому срока окупаемости в модели тоже нет.

```
Тарифы (₽/мес за одну точку):
  Аватар      — 24 900   физическое присутствие удалённого сотрудника
  Аватар + AI — 34 900   присутствие + автономная работа AI

Налоги (входные):
  НДФЛ 13%           — удерживается из оклада (сотрудник получает «на руки» меньше оклада)
  страховые взносы 30% — платит работодатель сверх оклада

Экономия:
  оклад              = «на руки» ÷ (1 − 0,13)
  стоимость сотрудника = оклад + взносы (30% от оклада)
  текущие расходы    = филиалы × стоимость сотрудника
  операторов         = ceil(филиалы / филиалов_на_оператора)
  аренда             = филиалы × тариф
  расходы с L.I.S.A. = аренда + операторов × стоимость сотрудника
  экономия           = текущие − расходы с L.I.S.A.   (в месяц; × 12 = в год)
```

Московский минимум: **80 000 ₽ «на руки»** → оклад 91 954 ₽ → НДФЛ 11 954 ₽ + взносы 27 586 ₽ →
полная стоимость для компании **119 540 ₽/мес** на человека (в калькуляторе это строка «на руки → оклад …»).

Проверка (5 точек, 1 оператор на 5 точек, тариф «Аватар + AI»):
597 700 ₽ → 174 500 ₽ аренды + 119 540 ₽ оператор = **294 040 ₽/мес**, экономия **303 660 ₽/мес** = **3,6 млн ₽/год** (51%).
Тот же расчёт на тарифе «Аватар»: 244 040 ₽/мес, экономия 353 660 ₽/мес = 4,2 млн ₽/год (59%).
Одна точка: 119 540 ₽ → 34 900 ₽ (в расчёте с оператором выходит минус — предупреждение `#cWarn`).

Важно: на 1–2 точках экономии нет — один удалённый оператор рассчитан на несколько точек.
Калькулятор честно показывает минус и выводит предупреждение (`#cWarn`).

## Что НЕ делать

- не подставлять AI-сгенерированные фото L.I.S.A.;
- не заявлять сертификаты, интеграции и клиентов, которых нет;
- не писать, что «камера ничего не записывает», пока это не реализовано технически;
- не превращать первый экран в «робот-компаньон».

## Локальная проверка

```
cd lisa-is-site && python3 -m http.server 8199
# открыть http://127.0.0.1:8199/index.html
```

Важно: страница использует ES-модули (`type="module"`), поэтому её надо открывать
по `http://`, а не двойным щелчком по файлу (`file://` не даст загрузить модули).
